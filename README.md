## 💡 Featured Work

### 1) Smart Home Security — Personalized Anomaly Detection (Research)

* Analyzed **40+ GB/month** of sensor data from **36,000+ devices** (PIR motion, contact, environmental).
* Built and compared **Isolation Forest**, **One‑Class SVM**, **Random Forest**, and **LSTM** baselines.
* Achieved **~68% false‑alarm reduction** vs. threshold‑based rules by modeling **time, duration, frequency, and context** features.
* Drafting a paper on **personalized anomaly detection for home security**.
  **Tech:** Python, NumPy, Pandas, Scikit‑learn, AWS (SageMaker, Glue, S3, CloudWatch)

> *Goal*: Safer smart homes with fewer nuisance alerts and more context‑aware detection.

### 2) Hogar Controls — IoT Integration Intern (Summer 2024 & 2025)

* Built integration workflows to register **Zigbee & Z‑Wave** devices with a central hub; ensured remote operation and stable connectivity.
* Debugged/optimized **firmware & APIs** for new device onboarding; incorporated user feedback to improve reliability.
* **Matter protocol POC** to unify application‑layer logic across device ecosystems.
* Cross‑protocol testing for consistent communication & performance; wrote **developer docs** for future maintainers.
  **Tech:** NXP i.MX93, Python, Java, C++, Node.js, Silabs Z‑Wave/Zigbee, JWT, AWS (EC2, S3, RDS, ECS)

> *Outcome*: Faster onboarding, better cross‑tech compatibility, and clearer docs for future engineers.
